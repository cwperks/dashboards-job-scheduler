## Maintainer Responsibilities

Maintainers are responsible for reviewing pull requests, triaging issues, guiding project direction, and helping keep the plugin aligned with OpenSearch Dashboards conventions.

## Becoming a Maintainer

New maintainers may be added as the project grows. Contributors interested in maintaining this repository should participate in issues and pull requests, then work with the existing maintainers and OpenSearch project governance process.
